# lazygit

`lazygit/lazygit.sh`

Install and launch [lazygit](https://github.com/jesseduffield/lazygit), a terminal UI for git. No config needed, operates on the current directory's git repo (prompts for a path if the current directory isn't one), same as the `git` CLI itself. `git` must already be installed: the script uses it to validate the repo but does not check for it. Commands: `install`, `uninstall`, `status`, `launch`.
